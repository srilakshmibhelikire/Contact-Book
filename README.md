📱 Contact Book Project

Description
This is a simple Contact Book project developed using Python.

The project allows users to:
- Add contacts
- View contacts
- Search contacts
- Delete contacts

This project was created as part of the Kodbud Python Programming Internship.

## Features
✔ Add New Contact  
✔ View All Contacts  
✔ Search Contact by Name  
✔ Delete Contact  

## Technologies Used
- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements

## How to Run the Project

1. Install Python
2. Download the project file
3. Open terminal or command prompt
4. Run the file using:
python contact_book.py

## Sample Output

1. Add Contact
2. View Contacts
3. Search Contact
4. Delete Contact
